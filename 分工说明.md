## 一、每个人具体要做什么（细化任务）

### 朱梦凡 —— 数据与算法（写函数）

**职责定位**：负责整条数据处理链的**核心算法与数据**，是六个 `wx_*` 工具背后"逻辑"的提供者。

**具体任务（细化）**：

| #   | 任务                                                                                                | 对应文件 / 产出                                                                             |
| --- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 1.1 | 从 DWD（德国气象局）开放数据源**获取**德国哈茨山及前麓 12 个站点的逐日气象数据（2000–2025）                                          | `tools/build_dataset.py` → 产出 `dataset/daily/*.csv`（12 个站）                            |
| 1.2 | **选站规则**：从全部可用站点中按地理分布、数据完整度、海拔梯度挑选 12 站                                                          | `build_dataset.py` 内的选站逻辑                                                             |
| 1.3 | **数据清洗与质量控制**：校验缺失、异常值、单位一致性，输出质量报告                                                               | `tools/check_quality.py` → 期望 **197 PASS / 1 WARN / 0 FAIL**                          |
| 1.4 | **判据标定**：用频率扫描法标定极端天气判定阈值（热浪 / 寒潮 / 暴雨）                                                           | `tools/calibrate_criteria.py` → 产出 `dataset/event_rules.json`（阈值：29°C / −13°C / 57mm） |
| 1.5 | **判据验证**：用已知历史极端事件复现校验，确保判定规则可信                                                                   | `tools/validate_criteria.py` → 8/8 已知事件一致                                             |
| 1.6 | 编写**数据源适配文档**：说明数据从哪来、怎么换地区/换源                                                                    | `tools/data-source-adapter.md`                                                        |
| 1.7 | 产出**数据集元信息**：站点清单、时段、来源、校验和                                                                       | `dataset/manifest.json`                                                               |
| 1.8 | 向成员2提供**六个工具的纯函数核心逻辑**（ingest / clean / thresholds / detect / backtest / report 的算法），供其封装进 AGH 插件 | 交付给成员2的算法说明 / 伪代码                                                                     |

> **交付给团队**：完整数据集 `dataset/` + 判定规则 `event_rules.json` + 算法核心逻辑 + 数据源说明。

### 李睿阳 —— AGH 集成与工程（在 AGH 上跑通）

**职责定位**：负责把成员1的算法**封装成 AGH 插件**，并搭好环境让 Agent 能真正调用，是"工程底座"。

**具体任务（细化）**：

| #   | 任务                                                                                                 | 对应文件 / 产出                                           |
| --- | -------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| 2.1 | 搭建环境：在 WSL 装 Node.js 24 + pnpm + 编译工具链                                                             | `setup.sh`                                          |
| 2.2 | 获取并构建 **AGH（Agnes Harness）** 源码                                                                    | `bootstrap.sh`（git clone → 构建）                      |
| 2.3 | 编写并维护 **profile.yaml**：provider 路由、模型配置（agnes-3.0-flash）、凭据指向、权限                                   | `bootstrap.sh` 内写入完整 profile                        |
| 2.4 | 配置 **AGH_HOME** 目录权限、写入模型 key（仅存凭据存储，不进项目文件）                                                       | `~/agh-deepblue-home/`                              |
| 2.5 | 把成员1的算法**封装成六个 AGH 工具**：wx_ingest / wx_clean / wx_thresholds / wx_detect / wx_backtest / wx_report | `panel/extensions/main/tools/*.mjs`                 |
| 2.6 | 实现**核心库与指标服务**：纯函数核心 + 面板指标计算                                                                      | `panel/extensions/main/core.mjs`、`metrics.mjs`      |
| 2.7 | 开发**前端面板**「极端天气监测」：监测范围、数据质量、识别结果、准确性、判定依据、历史回验                                                    | `panel/extensions/main/client/`、`agnes.client.json` |
| 2.8 | 编写并调试**插件安装与启停脚本**，保证换机可复现                                                                         | `bootstrap.sh`、`start-web.sh`                       |
| 2.9 | 在 Web 界面**跑通单工具调用**和**完整六步链**，确保 Agent 能自主规划并调用工具                                                  | 实测会话                                                |

> **交付给团队**：可运行的 AGH 环境 + 已装好的 weatherlab-panel 插件 + 六个工具的工程实现 + 前后端面板。
